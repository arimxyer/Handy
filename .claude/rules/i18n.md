# i18n Enforcement

All user-facing strings must use i18next translations — ESLint enforces no hardcoded strings in JSX.

- Use `const { t } = useTranslation(); t('key.path')` for all text
- Add new keys to `src/i18n/locales/en/translation.json` only — other locales are community-maintained
- Keys are nested objects, variables use `{{variable}}` syntax
- See `src/i18n/CLAUDE.md` for module internals and file structure
